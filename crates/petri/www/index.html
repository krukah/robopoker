Deep CFR, live

The neural crate's training loop — DeepCfr under external sampling, with CfrNet or the tabular MockNet — compiled to WebAssembly and running in a worker. Every number below is read from the live DeepProfile; none is simulated.

Checkpoints as a table

Quick look plateaus near 2× tolerance by epoch 2,048 and drifts to ~10× by 16,384; Bigger fits reach ~1.5× by 2,048 but drift to ~2.8× by 4,096, at ~16× the cost per epoch. Warm start continues each refit from the last weights: one run reached 0.85× at 16,384 epochs, though it swung to 3.7× on the way. Custom keeps steps and batch ≥ 256 and rate ≤ 2^-7; warm start at a high rate diverges. Changing a setting ends the run. A checkpoint fits the strategy net on M_Π and reads the average strategy; training never reads that net, so checkpoints only observe. MockNet ignores the shape and fit knobs: each fit is the exact t-weighted mean, the reference CfrNet is measured against.
